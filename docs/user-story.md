
# User Story KosFinder

## Latar belakang

Pencari kos kesulitan menemukan informasi kos yang sesuai lokasi, harga, dan fasilitas karena informasi tersebar di media sosial, grup WhatsApp, dan dari mulut ke mulut.

Pemilik kos butuh cara mudah mempublikasikan kos dan memperbarui ketersediaan kamar.

## Pengguna

- Pencari kos (tidak wajib login untuk melihat kos)
- Pemilik kos (wajib login untuk mengelola kos)

## User story

US01 Sebagai pencari kos, saya ingin melihat daftar kos, agar saya tahu pilihan yang tersedia.

US02 Sebagai pencari kos, saya ingin mencari kos berdasarkan area, agar hanya melihat kos di lokasi yang saya inginkan.

US03 Sebagai pencari kos, saya ingin menyaring kos berdasarkan harga maksimum dan fasilitas (wifi, kamar mandi dalam, parkir), agar sesuai kebutuhan dan anggaran.

US04 Sebagai pencari kos, saya ingin melihat detail kos (nama, alamat, harga, fasilitas, deskripsi, kamar tersedia), agar dapat memutuskan sebelum menghubungi pemilik.

US05 Sebagai pemilik kos, saya ingin mendaftar, masuk, dan keluar dari aplikasi, agar dapat mengelola kos saya.

US06 Sebagai pemilik kos, saya ingin menambahkan kos, agar kos saya dapat ditemukan pencari.

US07 Sebagai pemilik kos, saya ingin mengubah dan menghapus kos MILIK SAYA SENDIRI, agar informasinya selalu benar, dan pemilik lain tidak dapat mengubah kos saya.

US08 Sebagai pemilik kos, saya ingin memperbarui jumlah kamar tersedia, agar pencari tahu apakah masih ada kamar.
